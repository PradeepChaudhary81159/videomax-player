# VideoMax Player

**VideoMax Player** is a local video and music player for Android.  
It plays media files stored on the device — folders, playlists, continue watching, themes, private vault, and background playback with notification controls.

> Not a streaming / OTT app. It does not host or stream online movie catalogs.

---

## Features

- Local **video & audio** playback  
- Folder browse, playlists, favorites  
- Continue watching / resume position  
- Background playback + media notification controls  
- Optional **Picture-in-Picture** (device dependent)  
- **Private Vault** (PIN-protected local media)  
- Themes & accent colors  
- Gesture controls (brightness, volume, seek)
